# Changesets

This folder is managed by [changesets](https://github.com/changesets/changesets).
Every change that should ship to npm gets a changeset — a short markdown file
describing what changed and how each affected package's version should bump.

Add one with:

```sh
pnpm changeset
```

See the [common questions](https://github.com/changesets/changesets/blob/main/docs/common-questions.md)
for more detail.
