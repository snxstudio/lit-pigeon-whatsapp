Initial public release of the Lit Pigeon for WhatsApp toolkit under `@lit-pigeon`:

- `core` — WhatsApp message-template model and validator against Meta's Cloud API rules, plus starter templates and the supported-language list.
- `editor` — `<pigeon-whatsapp-editor>` and `<pigeon-whatsapp-preview>` Lit web components.
- `react`, `vue`, `svelte` — framework wrappers for the editor component.
- `mcp` — a stdio MCP server for AI-driven template authoring and validation.
- `cloud` — submit and list templates via Meta's Graph API.
